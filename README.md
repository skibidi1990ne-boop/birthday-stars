# Birthday Stars

Hiệu ứng chúc mừng sinh nhật bằng hạt sao:

- Sao tạo thành dòng chữ **CHÚC MỪNG SINH NHẬT BẠN**.
- Tự chuyển thành trái tim sao.
- Trái tim xoay chậm 360 độ và chuyển màu đỏ → hồng.
- Sao trắng lấp lánh xung quanh.
- Tự động loop; chạm màn hình để chuyển cảnh ngay.

Mở `index.html` là chạy được, không cần cài thư viện.
