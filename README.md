# Birthday Stars

Trang hiệu ứng chúc mừng sinh nhật bằng hạt sao: các sao tạo thành chữ **CHÚC MỪNG SINH NHẬT BẠN**, sau đó tan ra thành trái tim sao xoay chậm và chuyển màu đỏ sang hồng. Sao trắng lấp lánh xung quanh; hiệu ứng tự loop và có thể chạm màn hình để chuyển cảnh.

## Chạy online bằng GitHub Pages

Vào **Settings → Pages**, tại **Build and deployment** chọn **Deploy from a branch**, chọn nhánh **main** và thư mục **/(root)**, rồi bấm **Save**. Sau khoảng một phút, mở:

`https://skibidi1990ne-boop.github.io/birthday-stars/`

## Chạy local

Mở trực tiếp `index.html` trong trình duyệt; không cần cài thư viện.
